# 分诊标签

这些技能使用五种标准分诊角色。下表将标准角色映射到本仓库问题跟踪器中的实际标签名称。

| mattpocock/skills 中的标签 | 本仓库标签          | 含义                         |
| -------------------------- | ------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`      | 等待维护者评估               |
| `needs-info`               | `needs-info`        | 等待报告者补充信息           |
| `ready-for-agent`          | `ready-for-agent`   | 描述完整，可交给 AFK Agent   |
| `ready-for-human`          | `ready-for-human`   | 需要人工实现                 |
| `wontfix`                  | `wontfix`           | 不会处理                     |

当技能提到某个角色时，例如“添加可交给 AFK Agent 的分诊标签”，应使用本表中对应的实际标签名称。

如需适配已有的标签词汇，只需修改右侧“本仓库标签”列。

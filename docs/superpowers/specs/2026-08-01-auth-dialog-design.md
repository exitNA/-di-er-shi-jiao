# 认证弹窗

## 目标

未登录用户在当前页面完成登录或注册，不跳转到独立认证页。

## 交互

- 导航栏“登录”按钮打开 shadcn/ui `Dialog`。
- 弹窗可在登录与创建账号间切换，复用现有认证请求和校验。
- 成功后关闭弹窗并刷新当前页面，保留用户原来的位置与上下文。
- `/login` 和 `/register` 重定向到首页，不再提供独立认证页。

## 边界与验收

- 使用已有的 `src/components/ui/dialog.tsx`，不新增 UI 依赖。
- 保留接口的错误展示、加载状态和可访问性语义。
- 键盘关闭、焦点管理和遮罩由 Dialog 组件处理。

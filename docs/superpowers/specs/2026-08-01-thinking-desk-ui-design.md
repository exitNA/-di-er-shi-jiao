# 「思考桌」UI 重设计

## 目标

将「第二视角」塑造成一位可信、温和且具备行动力的 AI 思考伙伴。用户在提交内容、阅读报告或回看历史时，应始终清楚：系统正在帮助其展开证据与分歧，而不是替其下结论。

## 视觉方向

### 设计令牌

- 夜松绿 `#163A36`：主要文字、主操作与 Agent 识别色。
- 云雾蓝 `#DFF0EE`：第二视角与辅助信息的浅层背景。
- 暖瓷白 `#F8F7F2`：页面底色，避免纯白的疏离感。
- 晨杏 `#F4C99B`：温暖的提醒和重点标记。
- 墨灰 `#24302D`：正文和边框对比。
- 雾灰 `#DCE1DA`：分隔与禁用状态。

标题使用 `Noto Serif SC`（回退为系统衬线），正文使用 `Inter`，数据与状态使用等宽字体。大标题只在页面入口和报告标题使用，信息区以紧凑清晰的无衬线文字阅读。

### 结构与签名

全站采用一张居中的“思考桌”：顶部为小型工具栏，主体使用有留白的桌面区。首页的输入卡是桌上的一张待展开便笺；报告页以一条纵向的 Agent 状态轨串起各报告模块；历史是可继续打开的思考档案。

唯一高调装饰是“观点折光仪”：两个交叠的半透明色片对应第一、第二视角，在示例卡和关键报告状态中使用。它表达观点在经过更多证据后被重新看见，不表示某个观点正确。

## 页面与交互

### 导航与首页

- 固定但轻量的导航显示品牌、首页、思考档案及账户入口；活动页使用底部短线，而非额外的色块。
- 首页标题改为直接说明用户收益，输入框呈现为带状态标签的便笺卡。
- 有输入内容时，提交按钮显示「展开第二视角」；空内容保持明确不可用状态。
- 三个示例卡保留现有一键填入行为，改为折光仪视觉和更短的行动提示。

### 报告工作区

- 报告顶部展示分析状态、原文片段和已完成模块数，作为 Agent 工作状态，不使用泛化的仪表盘统计。
- 六个报告模块沿同一条“分析轨”排列；完成、生成中、待恢复状态使用文字、图标和颜色三重区分。
- 对某条内容提出质疑时，保留现有选中目标和对话流程，并让选中目标在对话区有清楚上下文提示。
- 桌面端报告和对话并列；窄屏回归单列且对话跟随在报告后，保证阅读顺序。

### 历史与空状态

- 历史记录使用档案条目，展示创建时间、进度、原文预览及「继续查看」操作。
- 空状态保留一条明确的开始路径，不增加插画或无关功能。

## 可访问性与适配

- 所有操作保持语义化按钮/链接、可见键盘焦点和足够的文字对比。
- 响应式断点优先保证 320px 宽度的输入、导航折行和单列报告。
- 仅为状态与折光仪提供短暂的淡入/浮动效果；`prefers-reduced-motion` 时关闭。

## 实现范围

仅修改现有应用壳、首页输入与示例、报告工作区、历史记录及全局主题样式；复用现有 `lucide-react`、表单提交、流式报告和对话逻辑，不新增依赖、路由或数据模型。

## 验收

- 首页、报告和历史页共享同一套「思考桌」视觉语言。
- 提交、填入示例、报告流式状态、模块重试、继续历史和账户入口的既有行为不变。
- 单元测试和类型检查通过；窄屏布局没有横向滚动。

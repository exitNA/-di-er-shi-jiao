# mark 分支采用 main 视觉界面设计

## 目标

保留 `mark` 分支已有的用户名认证、文本提交、六模块报告和历史记录能力，将所有用户可见页面统一为 `main` 分支的“第二视角”视觉语言：双色品牌、低饱和纸张底色、圆角卡片、强调色语义和适合阅读的排版。

## 范围

### 保留的产品逻辑

- 用户名和密码注册、登录、退出；
- 仅通过文本创建分析；
- 独立报告页中的速览、论证骨架、多视角地图、信源对照、认知风险和思考对话；
- 历史记录和打开既有报告。

### 迁移的界面设计

- 全局纸张色背景、靛蓝主色与青绿色辅助色、显示/正文/等宽字体层级；
- 双圆相交 Logo 与桌面、移动端一致的顶部导航；
- 带双色柔光背景的认证卡片；
- 首页的欢迎语、输入卡片和三张可直接填充文本的灵感示例；
- 可折叠的报告模块卡片，以及立场、风险、溯源和置信度的颜色与标签表达；
- 统一的圆角、边框、按钮、模态确认和轻量进入动画。

### 明确不迁移

- 游客登录、手机号登录、演示密码和找回密码；
- URL 提交和链接解析；
- `main` 中固定模板式的四模块分析内容。

## 页面与交互

### 全局导航

登录后的首页、报告和历史页显示固定顶部导航：左侧为 Logo 和产品名，右侧提供首页、历史记录及账户菜单。账户菜单显示用户名，可执行退出；退出前使用确认弹窗。认证页不显示导航。

### 认证页

登录和注册沿用 `mark` 的字段与服务端认证规则。页面使用居中的玻璃感卡片、双色背景和 Logo；登录、注册之间保留明确的跳转入口。表单错误继续就地呈现。

### 首页

欢迎文案使用 `main` 的语气与信息层级。文本输入仍显示字符限制和计数；提交按钮保持“开始分析”。输入区域之后放置职场、消费、教育三个灵感示例，点击后填入对应文字并回到输入区域，不自动提交。

### 报告页

报告保留六模块、现有内容和状态信息。模块改为带序号、强调色、可折叠的圆角卡片：论证/思考采用主色，多视角采用辅助色，风险采用提示色。展开时保留原有的溯源徽章、置信度和信源链接；立场、风险类型以颜色标签辅助扫读。

### 历史页

历史页纳入全局导航，采用与首页一致的卡片和排版。每条报告继续显示状态、时间、内容摘要、模块完成数和“打开报告”。

## 组件边界

- `Brand`：Logo、全局设计 token 和基础交互动效；
- `AppNavigation`：基于当前用户的导航与退出确认；
- `AuthSurface`：认证页背景与表单容器；
- `InspirationExamples`：仅向输入表单传入预填文本；
- `ReportModule`：管理折叠状态与模块视觉，内容组件维持各自的数据职责。

## 验收条件

- 用户能完成现有注册、登录、文本提交、查看报告、查看历史和退出流程；
- 首页示例点击后会预填文本但不会创建报告；
- 报告的六个模块可以独立展开或收起，内容、溯源、置信度与信源链接仍可见；
- 不出现游客、手机号登录、URL 输入或演示密码文案；
- 窄屏下导航、认证卡片、输入区、示例和报告卡片保持可用。

## 测试

- 更新首页、认证、报告模块和历史列表的组件测试，断言用户可见文案与交互；
- 新增示例预填和报告折叠测试；
- 保留并运行已有关键端到端流程，验证改造没有改变核心用户能力。

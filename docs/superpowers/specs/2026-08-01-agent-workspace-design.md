# Agent 工作台结果页

## 目标

将分析结果从静态报告改为可继续推进的双栏 Agent 工作台。用户在左栏与第二视角 Agent 对话，右栏实时呈现当前发现，并可从任一发现继续追问。

## 布局与交互

- 桌面端：全视口工作区，左栏默认 38%，右栏默认 62%。
- 中间提供可拖拽分隔条；其使用原生 range 控件语义，支持方向键微调并公布当前比例。
- 左栏滚动展示输入材料、Agent 过程消息、用户追问和固定在底部的输入框。
- 右栏展示当前发现，按主张、证据、分歧、风险组织为可点击结果卡，不使用报告章节或完成模块列表。
- 点击右栏发现会选中其对应报告条目，并在左栏输入区给出明确的追问上下文。
- 移动端在单列中切换“对话”和“当前发现”，不展示分隔条。

## 数据与边界

- 复用现有分析快照、流式更新、报告模块数据与质疑提交 API。
- 不改变分析生成、重试、历史记录或权限逻辑。
- 保留现有空态、错误与可恢复状态，但使用 Agent 工作语言而非报告语言。

## 验收

- 不出现“认知体检报告”“模块列表”“完成 x / 6”等结果页主叙事。
- 用户可鼠标或键盘调整桌面端栏宽，刷新前始终保持当前宽度。
- 用户可从右栏任意结果启动一次带上下文的追问。
- 流式状态更新时，右栏发现与左栏 Agent 状态同步刷新。
